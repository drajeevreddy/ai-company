# Anti-Slop Prose

Distilled from `humanizer` (34 patterns, Wikipedia Signs-of-AI-writing based) and `avoid-ai-writing` (severity tiers + modes). Part of [[Astra-Operating-System]]. Full references: `skill_view('humanizer')`, `skill_view('avoid-ai-writing')`.

## Process (every prose task)
1. Draft the rewrite.
2. Ask: "what makes this obviously AI-generated?" — list remaining tells.
3. Final revision. Show what changed for file edits.

## P0 — credibility killers (fix immediately)
- Chatbot artifacts: "Great question!", "I hope this helps!", "Let me know if…", "You're absolutely right!"
- Fake citations/placeholders, cutoff disclaimers ("as of…", "based on available information"), speculative gap-filling stated as fact.
- Vague attributions: "experts say", "industry reports", "observers note" — name the source or cut it.
- Sycophancy: flattery, recap-flattery openers, acknowledgment loops.

## P1 — obvious AI smell (fix before publishing)
- Banned vocabulary: delve, foster, leverage, crucial, pivotal, landscape (abstract), tapestry, testament, underscore/showcase/highlight (verbs), vibrant, enduring, intricate, interplay, garner. Blog-register twins: deep dive, game-changer, unpack, lean into, navigate (challenges), "at the end of the day", "when it comes to", "in a world where".
- Negative parallelism: "It's not X, it's Y." Tailing negations ("no guessing"). Rule-of-three stuffing. False ranges ("from X to Y" with no real scale).
- Copula avoidance: "serves as / stands as / boasts / features" → use is/are/has.
- -ing tacked-on depth ("underscoring…", "reflecting…", "contributing to…"). Promotional adjectives (nestled, breathtaking, groundbreaking, renowned).
- Significance inflation ("pivotal moment", "broader movement", "evolving landscape"). Formulaic Challenges/Future-Outlook sections. Generic upbeat closers ("exciting times lie ahead").
- Em-dash overuse, emoji decoration, bolded inline-header lists, Title Case Headings, "Let's dive in" signposting, rhetorical questions answered immediately.

## P2 — polish
- Sentence-opener tics (So…, Interestingly…, Importantly…), reassurance kickers ("And that's okay"), hyphenated-modifier stacking, synonym cycling, uniform rhythm.
- Fragmented headers (heading + one-line restatement). Manufactured punchlines.

## Soul check (clean ≠ human)
- Vary rhythm: short punch after long builds. Have an opinion; acknowledge mixed feelings. Use "I" where honest. One specific feeling beats one abstract concern. Cut anything that belongs on a motivational poster.
