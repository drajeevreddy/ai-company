# Instagram Reel Prompts Skill

Generate platform-ready AI video prompts for Instagram Reels, Stories, and carousels aimed at increasing followers, saves, and shares.

## When to Use

- User asks for Reel ideas for an Instagram page
- User asks for AI video prompts for tourism, lifestyle, or niche pages
- User wants hook formulas tailored to a specific audience

## How to Run

1. Identify niche from user input or audit context.
2. Output prompts grouped by format: Hook Reels, Story Reels, Carousel-to-Reel, UGC-style, Trending Audio Remix.
3. Include: visual prompt, on-screen text, voiceover, caption skeleton, CTA, and hashtag block.
4. Keep prompts production-ready for tools like Runway, Pika, CapCut, or HeyGen.

## Prompt Templates

- Hook-first: stop-scroll opener in 0–3 seconds, problem/desire statement.
- Transformation: before/after, map-to-reality, or process reveal.
- Local angle: hyper-relevant cultural or regional hook for India-first pages.
- CTA close: save/share/comment bait tied to the content.

## Pitfalls

- Avoid vague prompts; include shot type, pacing, text overlay, and audio direction.
- Do not overuse generic travel clichés unless the brand voice demands it.
